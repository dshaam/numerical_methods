
# Интерполяция функции: полиномы и сплайны

## Описание проекта

В данной работе исследуются методы численной интерполяции функции:

$f(x) = x \ln(x + 1)$

на интервале $[0.5, 2]$.

---
## Цель проекта

Реализовать и сравнить различные подходы интерполяции:

- полиномиальные методы (Лагранжа и Ньютона)
- сплайн-интерполяции (линейный, квадратичный, кубический)

Проект включает как реализацию алгоритмов, так и анализ их точности.

---
## Используемые технологии

- Python
- NumPy — работа с массивами и вычисления
- Pandas — формирование таблиц результатов
- Matplotlib — визуализация графиков

---

## Структура проекта

- `functions.py` — функция и генерация узлов Чебышёва
- `lagrange.py` — полином Лагранжа
- `newton.py` — полином Ньютона (разделённые разности)
- `splines.py` — сплайны ($S_{1,0}$, $S_{2,1}$, $S_{3,2}$)
- `visual.py` — построение графиков функций и ошибок
- `main.py` — основной запуск, вычисления и сохранение результатов

---

## Полиномиальная интерполяция

Реализованы:
- Полином Лагранжа
- Полином Ньютона

Для каждого метода используются:
- равноотстоящие узлы
- узлы Чебышёва (оптимальные)

Обозначения:
- (L_n), (N_n) — равномерные узлы
- (L_n^{opt}), (N_n^{opt}) — узлы Чебышёва

Для каждого (n):
- вычисляется максимальная абсолютная ошибка
- строятся графики интерполяции

---

## Сплайн-интерполяция

Реализованы сплайны:

- ($S_{1,0}$) — линейный
- ($S_{2,1}$) — квадратичный
- ($S_{3,2}$) — кубический

Для каждого типа:
- исследуется зависимость ошибки от числа узлов
- строятся графики

---

## Полученные результаты

### 1. Полиномы

- При увеличении числа узлов точность растёт, но:
    - для равноотстоящих узлов наблюдается **эффект Рунге** (осцилляции на концах интервала).
- Узлы Чебышёва:
    - значительно уменьшают погрешность
    - обеспечивают более равномерное приближение

Для наглядности, можно сравнить графики полиномов, построенным по 80 равноотстоящим узлам и узлам Чебышёва. Для полинома Лагранжа:
![[Lagrange_80_nodes 1.jpeg]]
Для полинома Ньютона ситуация аналогично, однако эффект Рунге наблюдается даже для полинома, построенного по 80 равноотстоящим узлам.
![[Newton_80_nodes.jpeg]]
Вывод:  
использование узлов Чебышёва важно для устойчивости полиномиальной интерполяции. Однако в некоторых случаях даже использование узлов Чебышёва не достаточно для построения интерполяции. В таких случаях следует использовать сплайны.

---

### 2. Сплайны

- Линейный сплайн:
    - простая реализация
    - низкая точность (разрывы производной)
        
- Квадратичный:
    - лучше сглаживает функцию
        
- Кубический:
    - даёт **наилучшее приближение**
    - гладкость до второй производной
        

Вывод:  
кубический сплайн ($S_{3,2}$) — лучший метод среди рассмотренных. Это очевидно, например, из графика для сплайнов, построенных из 10 узлов. 
![[Spline_10_nodes.jpeg]]
---

### 3. Сравнение (ключевой результат)

Сравнение:
- (L_n) (равномерные узлы)
- (S_{3,2}) (кубический сплайн)

Показывает:
- полином может сильно колебаться
- сплайн даёт стабильное и точное приближение

Итог:  
сплайны **устойчивее и практичнее** для численных задач.

## Визуализация

Проект автоматически строит:

- графики интерполяции
